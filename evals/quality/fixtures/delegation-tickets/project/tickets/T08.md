# T08: More coupon rules (builds on T07)

**Area:** `shop/orders.py`, `order_total`

This extends the coupon support added by T07; do T07 first.

## Acceptance criteria

- Coupon codes are case-insensitive and ignore surrounding whitespace: `coupon=" save10 "` works like `"SAVE10"`.
- A new code `FREESHIP` makes shipping free whatever the amount, with no discount:
  `order_total([("MUG", 1000, 1)], 800, coupon="freeship") == 1000`.
- Any other code raises `ValueError("unknown coupon: <code as given>")`, e.g. `ValueError("unknown coupon: BOGUS")`.
- Everything from T07 still holds.
