# T06: Low-stock list includes the threshold and has a stable order

**Area:** `shop/inventory.py`, `low_stock`

Purchasing reorders at the threshold, not below it, and the list order changes with the dict's insertion order.

## Acceptance criteria

- A SKU whose level equals the threshold is included: `low_stock({"A": 5, "B": 6}, 5) == ["A"]`.
- Lowest level first; SKUs with the same level are ordered alphabetically:
  `low_stock({"B": 2, "A": 2, "C": 5}, 5) == ["A", "B", "C"]`.
