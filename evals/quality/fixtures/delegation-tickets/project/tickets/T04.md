# T04: Readable negative and large prices

**Area:** `shop/pricing.py`, `format_price`

Refunds print as `$-2.50` for -150 cents (wrong sign placement and wrong amount), and large amounts are hard to
read.

## Acceptance criteria

- Negative amounts put the sign before the currency symbol: `format_price(-150) == "-$1.50"`,
  `format_price(-5) == "-$0.05"`.
- Whole currency units are grouped in thousands with commas: `format_price(123456789) == "$1,234,567.89"`,
  `format_price(100000) == "$1,000.00"`.
- Everything else is unchanged: `format_price(1234) == "$12.34"`, and the `currency` argument still replaces `$`
  (`format_price(-100000, "€") == "-€1,000.00"`).
