# T07: Coupon support in order totals

**Area:** `shop/orders.py`, `order_total`

Marketing launches the coupon code `SAVE10`.

## Acceptance criteria

- `order_total(lines, weight_grams, coupon=None)`: a new optional `coupon` argument; without it totals are
  unchanged.
- `coupon="SAVE10"` takes 10% off the subtotal, rounded to the nearest cent, halves up, before shipping is added:
  `order_total([("MUG", 1995, 1)], 800, coupon="SAVE10") == 2294` (1995 - 200 + 499 shipping).
- The free-shipping threshold is checked against the discounted amount: a 5500 subtotal with `SAVE10` is 4950, so
  shipping is charged; a 6000 subtotal with `SAVE10` is 5400 with free shipping.
- Other coupon codes are specified in T08.
