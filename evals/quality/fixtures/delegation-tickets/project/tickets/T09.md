# T09: Shipping charges every started kilogram

**Area:** `shop/orders.py`, `shipping_cost`

The docstring says 150 cents for every started kg above 1 kg, but a 1.2 kg parcel costs the same as a 1 kg one.

## Acceptance criteria

- Up to 1000 g: 499 cents (unchanged).
- Above that, 150 cents for every started 1000 g above the first kilogram: `shipping_cost(1001) == 649`,
  `shipping_cost(2000) == 649`, `shipping_cost(2001) == 799`, `shipping_cost(3500) == 949`.
