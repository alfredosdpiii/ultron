# T12: Best sellers are listed best first

**Area:** `shop/report.py`, `top_sellers`

`top_sellers` returns the SKUs with the lowest revenue.

## Acceptance criteria

- `top_sellers(orders, limit)` returns up to `limit` `(sku, revenue)` pairs, highest revenue first.
- SKUs with the same revenue are ordered alphabetically.
- Example: orders `[[("A", 100, 1), ("B", 300, 1)], [("C", 300, 1), ("D", 50, 1)]]` with `limit=3` give
  `[("B", 300), ("C", 300), ("A", 100)]`.
