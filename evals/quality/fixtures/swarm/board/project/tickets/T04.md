# T04: Round converted amounts

**Area:** `ledger/money.py`, `convert`

Conversions truncate today; finance wants rounding to the nearest cent.

## Acceptance criteria

- Round to the nearest cent, halves away from zero: `convert(1000, 1.0825) == 1083`, `convert(-1000, 1.0825) == -1083`,
  `convert(999, 0.5) == 500`.
- Exact results are unchanged: `convert(1000, 1.5) == 1500`.
- Use decimal arithmetic on the rate as written (`str(rate)`), so `convert(1005, 1.1) == 1106` (1105.5 rounds up).
