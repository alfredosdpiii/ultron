# T01: Parse amounts as customers type them

**Area:** `ledger/money.py`, `parse_amount`

Amounts come from a web form and from CSV imports.

## Acceptance criteria

- Surrounding whitespace is ignored: `parse_amount("  12.34 ") == 1234`.
- Thousands separators are accepted: `parse_amount("1,234.50") == 123450`.
- Negative amounts work: `parse_amount("-12.34") == -1234` and `parse_amount("-0.50") == -50`.
- Whole amounts and one decimal still work: `parse_amount("7") == 700`, `parse_amount("7.5") == 750`.
- More than two decimals, an empty string or anything that is not a number raise `ValueError`.
