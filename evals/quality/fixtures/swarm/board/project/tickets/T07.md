# T07: Validate account ids

**Area:** `ledger/accounts.py`, `account_id_valid`

## Acceptance criteria

- A valid id is `AC-` followed by exactly seven digits, where the last digit is a check digit: the sum of the first
  six digits modulo 10. `account_id_valid("AC-1234561") is True` (1+2+3+4+5+6 = 21), `"AC-1234567"` is not.
- Anything else is invalid: lowercase prefix, missing dash, other lengths, non-digits, surrounding spaces.
