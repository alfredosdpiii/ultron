# T06: Overdraft fee only for real overdrafts

**Area:** `ledger/accounts.py`, `overdraft_fee`

## Acceptance criteria

- A balance of exactly 0 is not overdrawn: no fee.
- Small overdrafts are forgiven: no fee while the balance is above -500 (less than $5.00 overdrawn).
- From -500 down the fee is `OVERDRAFT_FEE`: `overdraft_fee(-500) == 3500`, `overdraft_fee(-499) == 0`.
