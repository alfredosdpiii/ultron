# T02: Format negative and large amounts

**Area:** `ledger/money.py`, `format_amount`

## Acceptance criteria

- Negative amounts put the sign before the currency: `format_amount(-1234) == "-$12.34"`
  (today it prints `$-13.66`).
- Thousands are grouped with commas: `format_amount(123456789) == "$1,234,567.89"`.
- The currency argument still works: `format_amount(-5, currency="EUR ") == "-EUR 0.05"`.
